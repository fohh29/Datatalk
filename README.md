## 🌟 Project Overview
DataTalk is a conversational analytics tool developed by **Fouziya** as part of the **AI-ML Development Course**. It allows users to upload raw datasets, clean them automatically, and perform deep-dive analysis using natural language.

## 🚀 Features
- **Smart Data Cleaning:** Automatically handles missing values and converts complex data types (like 'K' values in game stats).
- **Outlier Detection:** Uses the IQR (Interquartile Range) method to identify data anomalies.
- **Conversational AI:** Integration with OpenAI via PandasAI to generate charts and tables through chat.
- **Dynamic Visualizations:** Supports Pie charts, Bar charts, and more.

## 🛠️ Tech Stack
- **Language:** Python
- **Interface:** Streamlit
- **AI/LLM:** OpenAI GPT-4
- **Libraries:** Pandas, PandasAI, Matplotlib
