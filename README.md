# DataTalk: Conversational Analytics Engine

DataTalk is an AI-driven tool designed to simplify data analysis. It allows users to upload raw CSV files, clean them automatically, and ask questions in plain English to generate insights and visualizations.

## 🚀 Features
- **Smart Cleaning:** Automatic column standardization and missing value handling.
- **Anomalies:** Outlier detection using the Interquartile Range (IQR) method.
- **AI Chat:** Natural language querying powered by OpenAI.
- **Visuals:** Auto-generation of charts and graphs.

## 🛠️ Setup
1. Clone the repository.
2. Install dependencies: `pip install -r requirements.txt`
3. Run the app: `streamlit run app.py`
